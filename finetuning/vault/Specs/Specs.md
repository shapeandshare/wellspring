# Specs

Feature specifications for this repository would be spec-kit artifacts living in a top-level
`specs/` directory (created via `/speckit.specify`) — **none exist yet**. This note is a
pointer, not a home for spec content.

## How specs relate to the vault

- Architecturally significant decisions made while writing a spec belong in an [[ADL/README|ADR]], linked from both sides.
- Smaller decisions an agent resolves while implementing a spec belong in a [[Decisions/Decisions|Decision]] note.
- Non-obvious constraints found while implementing a spec belong in a [[Discoveries/Discoveries|Discovery]] note.
- Implemented subsystems described by a spec are documented in [[Systems/Systems|Systems]].
